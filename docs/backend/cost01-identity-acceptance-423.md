|---|---|

- CostCenterTests: هوية مولدة، الرمز 00042 والاسم العربي، إعادة الطلب، رفض الرمز المكرر وغير الصحيح والاسم الفارغ، وثبات التدقيق والإصدار.
- FoundationSqlIntegration: تنافس إنشائين على الرمز نفسه، قبول واحد فقط، عدم حفظ إيصال للطلب المرفوض، السماح بالرمز نفسه لشركة أخرى دون مشاركة الهوية، والتحقق من الحقول المحفوظة في SQL.
- HostedApiIntegration: حفظ الهوية والشركة والرمز والاسم عبر HTTPS/JWT، إعادة الطلب بالمعرف نفسه، رفض التكرار برمز الخطأ الموثق، وحدث إنشاء واحد.
- قواعد BR02/09/18 وحماية الشجرة تبقى كما في المصدر والاختبارات القائمة. عرض النص بأمان في واجهة المستخدم ليس جزءًا من تنفيذ backend. لا تعديل للتحليل أو المخطط أو عقد API أو SQL؛ تبقى F11 وسياسات الموازنات غير مكتملة. القبول النهائي مشروط بنجاح CI.
