الترتيب حسب Code ثم Id؛ العدد الكلي بعد المرشحات وقبل الصفحات. البحث نصي حتى 100 محرف، والصفحات من 1 إلى 200 عنصر. المركز العام ظاهر للقارئ ذي نطاق فرع، لكن مركز فرع آخر ليس ظاهرًا؛ لا تجميع للأرصدة أو تعديل للبطاقة.

## أدلة التحقق
- CostCenterTests: مرشح الحالة والأب والفرع، ترتيب ثابت وصفحات، رفض حدود البحث والصفحات، وثبات Version. اختبار النطاق الموجود سابقًا يثبت استبعاد مركز الفرع الآخر ورفض الأب المحجوب.
- FoundationSqlIntegration: بحث عربي ورمز ومرشح الحالة/الفرع/الأب عبر SQL، صفحتان وثبات الإصدار والتدقيق. الاختبارات القائمة تغطي المراجع المركبة داخل الشركة.
- HostedApiIntegration: بحث الرمز والاسمين، مركز معطل وصفحة فارغة بعد آخر نتيجة، وعدم زيادة أحداث التدقيق. الاختبارات القائمة تغطي المصادقة ونطاق القراءة؛ لا ندعي إضافة اختبار HTTP خاص بكل حالة رفض البحث.
- لا تغيير في عقد API أو المصدر التحليلي أو حالة الشاشة الجزئية. لا يُحتسب F11 أو التنفيذ التشغيلي للموازنات مكتملًا. القبول النهائي بعد CI، وأي فجوة في إثبات عزل البحث على SQL/HTTPS تبقى موثقة ولا تُخفى.


## استكمال إثبات SQL

تضيف دفعة المتابعة اختبارًا على بيانات اصطناعية: عضو فرع محدد يرى المركز العام فقط في مجموعة البحث، ويرفض مرشح فرع وأب خارج نطاقه؛ شركة أخرى لها الرمز نفسه ولا تدخل نتائج الشركة الأولى؛ عضو بلا عضوية في تلك الشركة يرفض. الدليل النهائي مشروط بنتيجة CI. تغطية حالات رفض البحث الخاصة عبر HTTPS/JWT ما زالت مطلوبة؛ لا إغلاق تلقائي للقضية.
