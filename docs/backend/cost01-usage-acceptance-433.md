# COST01-OP05 — قبول عرض الاستخدام

القضية [#433](https://github.com/ameenalqershi/wow-erp/issues/433). المصدر [COST01](../../muhaseb-erp-analysis/docs/modules/COST.md)، [الحقول](../../muhaseb-erp-analysis/data/fields.csv) و[عقد مراكز التكلفة](currencies-and-cost-centers.md).

- GET /companies/{companyId}/cost-centers/{id}/usage يطلب ledger.read ونطاق جميع الفروع. النتيجة تشمل عدد الأبناء المباشرين والمراجع المباشرة للقيود والقوالب وعلم الاستخدام في الشجرة. لا تُخلط مراجع الأبناء بالمراجع المباشرة.
- CostCenterTests يثبت ظهور القيد الملغى والقالب المعطل، صفحتين متتاليتين دون ازدواج، رفض حجم صفحة غير صالح وعضوية الفرع المحدودة، وثبات الإصدار والتدقيق بعد القراءة.
- FoundationSqlIntegration يثبت مطابقة معرف القيد والفرع المرجعي في SQL، فصل استخدام الشجرة عن المباشر، الصفحة الفارغة بعد آخر مرجع، وثبات نسخة البطاقة ورفض مرجع شركة أخرى.
- HostedApiIntegration يثبت المرجع الحقيقي عبر HTTPS/JWT، حد الصفحة، رفض حجمها غير الصالح والعضوية المحدودة أو الغائبة، وعدم إضافة أحداث تدقيق لقراءة الاستخدام.

لا تغيير لعقد API أو الترحيلات أو التحليل. لا ادعاء بضمان snapshot متعدد الطلبات أو تجميع الأرصدة المالية للأحفاد؛ كلاهما خارج عقد عرض الاستخدام الحالي. حالة COST01 تظل جزئية لأسباب F11 والموازنات. القبول النهائي للقضية بعد نجاح CI.
