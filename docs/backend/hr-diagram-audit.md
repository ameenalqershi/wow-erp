## الفجوات والقبول

- BR02/09/18 مشتركة في الشاشات السبع؛ HR03 وHR07 تضيفان BR01/03/05/06/07/10. المرجع [قواعد الأعمال](../../muhaseb-erp-analysis/docs/02-accounting-and-business-rules.md).
- يجب إثبات الصلاحيات الدقيقة وسرية الأجور، تثبيت نسخ السياسات والعقود حسب تاريخ النفاذ، منع ازدواج المدخلات والمسير والأقساط، والتزامن والذرية في الأثر المحاسبي. لا تُستنتج معدلات أو سياسات قانونية غير محددة في المصدر.
- AT22 في [سيناريوهات القبول](../../muhaseb-erp-analysis/docs/07-workflows-and-acceptance.md): مسير معتمد وأمر دفع رفضه البنك؛ يبقى استحقاق الراتب، ولا يعتبر ملف الدفع سدادًا نهائيًا. معيار مستقبلي وليس اختبارًا منفذًا.
- ارتباطات CASH04 وHR05 ليست إثباتًا لوجود تكامل تشغيلي. لا تغيير للمصدر أو API أو SQL أو حالة المصفوفات، ولا ادعاء بتنفيذ الرواتب.
