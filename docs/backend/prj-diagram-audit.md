## الفجوات والقبول

- BR02/09/18 لجميع الشاشات؛ PRJ02–04 تضيف BR01/03/05/06/07/10، وPRJ03/04 تضيف BR12/13. [القواعد الأصلية](../../muhaseb-erp-analysis/docs/02-accounting-and-business-rules.md). يلزم إثبات عزل الشركة والفرع والصلاحيات والتدقيق، وتثبيت النسخ، والتزامن ومنع الازدواج، وترحيل ذري بحسب الأثر.
- AT24 في [سيناريوهات القبول](../../muhaseb-erp-analysis/docs/07-workflows-and-acceptance.md): مستخلص 1000 واحتجاز 100 قبل الضريبة؛ إجمالي المطالبة 1000 موزع إلى مستحق 900 ومحتجز 100؛ الضريبة وفق قواعدها. هذا معيار مستقبلي لا نتيجة اختبار.
- التبعيات الوظيفية الواردة في الجدول ليست أسهم القائمة. وجود بنى الأستاذ أو المخزون أو النقد لا يثبت عقد التكامل للمشروعات. يجب اعتماد سياسة الاعتراف والتسويات وتطبيق الضريبة وفق التحليل، لا اختلاق معالجة تشغيلية.
- لا يوجد إثبات تشغيل مستقل لهذه الشاشات على المرجع المدقق. لا تغيير لملفات المصدر أو الحالات أو SQL أو API. اكتمال نطاق القضية هو اكتمال تدقيق المخطط فقط.
