## الواقع والفجوات

HR01–06 وCASH04 not-started؛ لا مسار مسير أو تقرير رواتب في ReportsEndpoints، ولا دليل على محرك الرواتب أو ربط القسط أو التسوية البنكية في التنفيذ الحالي. RC16 وAT22 not-verified. الأستاذ العام قد يعرض قيودًا عامة لكنه لا يثبت تطابق الموظفين أو الاستحقاقات أو حالة السداد. أصل قواعد الترحيل يفصل مصروف الرواتب ومساهمات صاحب العمل عن مستحق الموظف والاستقطاعات والالتزامات، ويخصص السلفة لحساب السلف والسداد مستقلًا.

BR02/09/18: نطاق الشركة والفروع والسرية وصلاحيات التكلفة والتصدير والتدقيق؛ لا تسريب حساب البنك أو كامل المسير لمستخدم قراءة أستاذ عام. BR05/06/07: ذرية القيد والأثر المساعد وعدم تكرار الترحيل/الخصم تحت التزامن. لا افتراض سياسة دولة أو معادلة صافي سالب أو تحويل عملة أو صفة نجاح ملف دفع غير معتمدة.

## بوابات إعادة القبول قبل إغلاق التنفيذ

- ثبات نسخة العقد والسياسة والمدخلات ومجموع الصافي قبل السداد، مع مصدر سطر موظف وقيد استحقاق قابل للمطابقة؛ اختبار تصحيح لاحق دون تغيير المسير الأصلي.
- قسط واحد لكل استحقاق، رفض إعادة استيراد المدخلات وترحيل/صرف مكرر، ومطابقة المبالغ عبر الشركة والفرع والفترة والعملة.
- رفض البنك يبقي الاستحقاق كما هو؛ تأكيد دفع جزئي أو كامل يطابق الأثر الفعلي دون خصم مكرر؛ إعادة القبول عند تنفيذ HR03/05/06 وCASH04.
- عزل البيانات الحساسة، صلاحيات العرض والطباعة والتصدير المستقلة، أثر استخراج، مصدر واحد للأرقام والمرشحات؛ اختبار SQL/HTTPS/JWT والتزامن والانحدار عند تنفيذ المسارات.
- لا اعتبار نجاح حراس التحليل أو هذا التدقيق إثباتًا لـAT22 أو RC16؛ تبقى مهام المصادر والشاشات مفتوحة.
