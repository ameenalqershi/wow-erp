## التغطية والدليل

[لقطة التتبع](rpt-sales-contract-fields-20261127.csv) تطابق 408 معرفات أصلية فريدة: SAL01–15 (331)، RPT05 (12)، INV08/14/15 (65). تحفظ الاسم والنوع والإلزام والمصدر والافتراضي والتحقق والظهور وحالة الربط عند المرجع. جميعها pending في مصفوفة التنفيذ؛ هذه ليست دعوى غياب كل شفرة. مخطط SAL فيه 15 شاشة و5 مجموعات قائمة و20 وصلة؛ RPT05 في مسار RPT04→RPT05→RPT06. الوصلات للتنقل وليست ترتيب الاعتراف المالي.

- SalesMovementReportFilter وSalesMovementReportVisibility في المجال يثبتان مرشحات SAL13 وحجب Cost/Profit من إسقاط محدد، بشرط نطاق فرع وصلاحية يوفرهما مستدع موثوق. SalesMovementReportFoundationTests يختبر حفظ المرشحات ورفض النطاق وحجب التكلفة. لا خدمة تقرير أو API أو استعلام SQL تشغيلي أو مصادقة داخل هذه الكائنات. القيم النصية للسياسة opaque، ولا حساب للصافي أو الهامش. الحجب ليس تفويضًا إنتاجيًا.
- Customer وSalesOrder وSalesDeliveryOrder وCustomerCollectionFollowUp موجودة كأسس؛ راجع CustomerFoundationTests/CustomerSqlIntegration وSalesOrderFoundationTests وSalesDeliveryOrderFoundationTests وCustomerCollectionFollowUpFoundationTests. لا تعادل فواتير مبيعات ومرتجعات مرحلة أو سجل تقييم كامل.
- لا مسار RPT05/SAL13 في ReportsEndpoints، ولا دليل لاحتساب هامش أو تصديره. لا نغير مصفوفة التنفيذ أو حالة RC11 not-verified، ولا نعيد تنفيذ الأسس.

## مرشحات RPT05 وSAL13

F01–F08 في كلتا الشاشتين: الشركة، الفروع، الفترة، عملة العرض، طريقة عرض العملات، حالة المستندات، مستوى التفصيل. الشركة من الجلسة؛ الفروع ومرجع العملة مقيدان بالشركة والصلاحيات؛ F06–F08 من قوائم سياسة غير محسومة. لا نفترض قيمًا أو افتراضات. RPT05-F09/F10/F11 العميل والصنف والمندوب اختياريًا وF12 مستوى التجميع إلزامي. SAL13-F09/F10/F11 العميل والمندوب والصنف اختياريًا وF12 نوع البيع اختياري. لا نساوي مستوى التجميع بنوع البيع. تحقق صلاحيات الحساب والعميل والمندوب والصنف على مستوى الاستعلام والحفر والطباعة والتصدير؛ مرشح موجود ليس دليل تنفيذ.

## مطابقة الأعمدة

| العمود | المصدر والبوابة |
|---|---|
| العميل/المندوب/الصنف | SAL01/09/15 وINV04؛ هوية تاريخية ضمن الشركة والنطاق، لا كشف كل العملاء للمندوب |
| الإجمالي والخصم | سطور SAL06 وأسعار/خصومات مثبتة؛ SAL02 سياسة السعر، SAL04/05 سياق لا إيراد إضافي |
| المرتجع | SAL07 وسطر الأصل، INV14 للعزل، SAL08 إشعار مالي لا كمية |
| الصافي | صافي الإيراد دون ضريبة وفق RPT05، بعد المرتجعات والتعديلات المعتمدة؛ فصل التحصيل والمقدمات عن الإيراد |
| التكلفة | INV08/15 طبقات تقييم تاريخية وربط المصدر، تكلفة المصدر للمرتجع السليم وفصل التالف؛ لا استعمال السعر الحالي |
| الربح والهامش | الربح = الصافي − التكلفة؛ الهامش = الربح ÷ الصافي؛ عند صافي صفر تكون النسبة غير معرفة، لا صفر مصطنع أو قسمة على صفر |

التجميع من السطور الأصلية مرة واحدة: تجمع مبالغ الصافي والتكلفة ثم تحسب نسبة المجموعة، لا متوسط نسب الصفوف. مثال عقد فقط: صافي 100 وتكلفة 70 مع صافي 20 وتكلفة 18 → هامش إجمالي 32/120، لا متوسط 30% و10%. إذا كان صافي المجموعة صفرًا يبقى الهامش غير معرف حتى لو وجد ربح/خسارة. هذا اختبار متوقع من SPEC08، وليس نتيجة محرك عامل. لا نفترض سياسة عرض الإشعار أو المرتجع عبر فترة سابقة.

## الاعتماديات والقبول

RPT05 يرتبط SAL13 وINV15؛ SAL13 يرتبط SAL06/SAL07/RPT05؛ SAL05 يرتبط INV08/SAL06؛ SAL06 يرتبط SAL05/CASH03/TAX05؛ SAL07 يرتبط SAL06/INV14/TAX05؛ INV15 يرتبط IMP06/GL10. SYS03/04/05 للفترة والعملة والسعر، SYS07 #2616 وSYS08 #2631 للتفويض والنطاق، GL06/GL10 للأثر والمطابقة. SAL09/10 للهوية والعمولات عند انطباق السياسة؛ SAL11/12 للتحصيل والائتمان وليسا إيرادًا إضافيًا. قضايا المصادر والتقييم الفعلية تظل مفتوحة. لا نفترض اعتمادًا أحاديًا من كل وصلة.

- BR01/05/07/10: اتزان، إعادة الطلب بلا أثر مزدوج، عكس مستقل، سعر مؤرخ؛ لا إعادة كتابة التاريخ.
- BR11/12/13: عدم تجاوز المرتجع المتبقي تحت التزامن، منع إخراج مخزون مزدوج من تسليم وفاتورة، تحقق المتاح والائتمان داخل الترحيل، حفظ سطر الأصل والكمية.
- BR18 وSAL13: لا كشف التكلفة أو الربح أو الهامش أو أي مجموع أو تصدير يمكن استنتاجها منه دون صلاحية مستقلة؛ اختبارات سلبية للحفر والطباعة والتجميع. عدم كشف عملاء أو فروع خارج النطاق. رفض مرشحات غير مدعومة.
- RPT05: صافي دون ضريبة؛ اختبار الخصم والمرتجع والإشعار والتكلفة اللاحقة بحسب تاريخ الأثر والسياسة، صفر صافي، تكلفة غير متاحة ليست صفرًا، تجميع صحيح ومطابقة مع الأستاذ والتقييم.
- SPEC08: بيانات تعريف الاستخراج، المرشحات نفسها في العرض والطباعة والتصدير، أثر تدقيق مستقل، اختبارات SQL/HTTPS/JWT وOpenAPI والقبول تحت التزامن.

لا اختبار تشغيل فعلي لتقرير غير موجود؛ هذا التدقيق لا يغير المحرك. عند تغير أي مصدر يعاد تقييم العقد واللقطة واختبارات الانحدار قبل إعلان التشغيل. التبعيات تمنع القبول التشغيلي لا إغلاق التدقيق المحدد عند المرجع. لا تعديل للتحليل الأصلي.
