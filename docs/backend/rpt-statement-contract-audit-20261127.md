# RC03 — تدقيق عقد كشف العميل والمورد (#2013)

المرجع: main عند 1c26a13. RC03 يطابق RPT-CONTRACT-03 وفق [SPEC08](../../muhaseb-erp-analysis/docs/08-reports-and-roadmap.md) و[مصفوفة العقود](core-spec08-report-contracts.csv). RC04 عقد أعمار الذمم منفصل. هذا تدقيق تغطية وليس تنفيذ تقرير أو قبول تشغيلي.

## المسار والحقول

[مخطط RPT](../../muhaseb-erp-analysis/diagrams/source/module-RPT.mmd): التقارير والتحليل ← التقارير؛ RPT12 → RPT13 → RPT14. الاعتماديات من screens.csv و[RPT.md](../../muhaseb-erp-analysis/docs/modules/RPT.md): RPT13 يرتبط بـSAL01 وSAL11 وRPT06؛ RPT14 يرتبط بـPUR01 وPUR11 وRPT07. المصادقة لا تشمل حركات بعد تاريخ القطع.

[لقطة الحقول](rpt-statement-contract-fields-20261127.csv) تطابق معرفات وأسماء وإلزام الحقول الأصلية مع المصفوفة؛ 12 حقلًا لكل شاشة، جميعها pending. F01–F08 في كل منهما الشركة والفروع والفترة وعملة العرض وطريقة العملات وحالة المستند ومستوى التفصيل؛ F09 طرف العميل/المورد، F10 تفصيلي/إجمالي، F11 فواتير مفتوحة للعميل أو مقدمات للمورد، F12 حركة/مصادقة. لا تُنقل حالات حقول RPT01/02 إلى شاشة غير منفذة.

## مطابقة عقد التقرير

| المطلوب | المصدر المطلوب بحسب التحليل | حالة التنفيذ |
|---|---|---|
| فاتورة وقيمة واستحقاق | SAL06 وPUR07، بطاقات الطرف SAL01/PUR01، بنود ذمم بتاريخ أثر واستحقاق | لا مسار تقرير طرف أو دفتر بنود مفتوحة في main |
| دفعات وتخصيص | SAL11 وPUR11، ربط مستند القبض/السداد بالفاتورة والمبلغ وتاريخ الأثر | غير منفذ تشغيليًا |
| إشعارات ومردود | أحداث الإشعارات والمرتجعات المرتبطة بالفاتورة | لا سلسلة تقرير تشغيلية تربطها بالذمة |
| رصيد ومدين ودائن | افتتاح طرف، حركات مرحلة، تخصيص تاريخي، رصيد كل طرف | الأستاذ العام يحسب رصيد الحساب لا رصيد كل فاتورة |
| فصل المقدمات | BR16، لا تخصيص يتجاوز المفتوح أو المبلغ القابل للتخصيص | لا دليل تشغيلي على الفصل والتخصيص |
| مجموع البنود المفتوحة = الرقابة بعد فصل المقدم | GL10 ودفتر مساعد قابل للمطابقة بنفس الشركة والفترة والعملة | GL10 غير منفذ؛ لا مطابقة عامة ولا قيد تلقائي لإخفاء الفرق |

## حدود التنفيذ القائم

[ReportService](../../backend/src/Ameen.Erp.Application/Features/Report/ReportService.cs) يوفر الأستاذ العام بالعملة الوظيفية مع الفترة والفروع ومركز التكلفة والمرجع الخارجي؛ لا يعتبر المرجع الخارجي معرف طرف أو رابط فاتورة/دفعة. [ReportsEndpoints](../../backend/src/Ameen.Erp.Api/Endpoints/ReportsEndpoints.cs) و[OpenAPI](../../backend/openapi/v1.json) لا يوفران كشف عميل أو مورد أو مصادقة أو أعمار ذمم. فحص نطاق الشركة والفروع في الأستاذ لا يثبت صلاحيات طرف أو تخصيص أو تصدير. لا تحويل عرض أو طباعة/تصدير مطابق لهذا العقد. لا ختم استخراج مستقل للكشف غير المنفذ.

BR02 يعزل الشركة والطرف والحساب؛ BR05 يتطلب ذرية أثر اليومية والذمم؛ BR15 يستبعد المسودات؛ BR16 يمنع التخصيص الزائد ويفصل المقدم؛ BR18 يتطلب صلاحيات الفرع والحساب والتصدير والتدقيق. لا يكفي اختبار اتزان قيد عام لإثبات ذمم. يجب حفظ الأثر التاريخي وسعر المصدر وعدم إسقاط دفعة لاحقة على مصادقة سابقة. AT08 وAT09 وAT10 وAT15 تبقى not-verified؛ AT25 دليل عزل عام وليس قبول عقد كشف الطرف. لا سياسة صرف أو تصنيف مقدمات جديدة بهذا التدقيق.

التوصية: تفعيل بطاقات الطرف ثم دفاتر الفواتير والإشعارات والتخصيص الذري، فمطابقة GL10 وقراءة تاريخية واختبارات المصدر والصلاحيات. بعدها فقط مصادقة وطباعة وتصدير طبق الأصل. حالة RPT13/14 not-started، RC03 not-verified، لا تغير في نسبة تنفيذ الحقول. يجوز إغلاق #2013 كتدقيق تغطية عند قبول الوثائق دون إغلاق مهام التشغيل.
