## بوابات حماية المنجز

- SYS01–05: استمرار الهوية المركبة للشركة والفرع؛ حماية البطاقات المستخدمة والقيم التاريخية في القيود؛ لا استنتاج لنوع سعر أو فرع غير محدد؛ إعادة اختبار GL03/08/11/12 وCOST01 وINV06 عند تعديل سياسات التقويم والعملات والنطاق.
- SYS06–08: الأدوار والنطاقات التفصيلية ليست مكتملة تشغيليًا. عند تفعيل الإدارة لا يجوز توسيع الصلاحيات القائمة ضمنيًا، أو تجاوز المنع الصريح، أو خلط صلاحيات القراءة/التكلفة/الطباعة/التصدير/الترحيل؛ إعادة اختبار API والتقارير والمرفقات وعمليات إعادة الطلب تحت سحب الصلاحية. أساس UserDataScope ليس ضمان تطبيقه في كل مستهلك. لا اعتبار غياب النطاق إذنًا عامًا دون عقد مصدر.
- SYS09/17: اعتماد ذري على الإصدار والحالة ونطاق الممثل وقت القرار؛ حماية تدفق GL03/05 والقيد ومراجعة فصل الصلاحيات؛ عدم قبول المهلة تلقائيًا أو إنشاء اعتماد ثانٍ للوثيقة نفسها.
- SYS10: الترقيم التشغيلي الحالي Journal وInventoryOpening فقط حسب مصفوفة الشاشات؛ يلزم ربط كل مصدر جديد بالمعاملة نفسها ومنع التكرار وعدم إعادة استخدام الرقم؛ الترقيم الضريبي معطل إلى أن تتوفر قواعد TAX05.
- SYS11/12/16: تثبيت السياسة المؤرخة وحسابات الربط الفعالة وعدم إعادة تفسير التاريخ؛ قوالب الطباعة لا تغير الأصل أو تقلل صلاحياته أو تحذف حقول الدولة؛ اختبار مستقل للطباعة والتصدير. عدم تسجيل البطاقة نقدًا.
- SYS13/15: لا تنفيذ مباشر لبيانات دفتر الأستاذ خارج ضوابط المصدر؛ إثبات إعادة الاستيراد بلا ازدواج، مطابقة الحسابات، اختبار استعادة معزول قبل تشغيله؛ عدم الادعاء بجدولة نسخ أو استعادة من وجود كيان فقط.
- SYS14: الحفاظ على الأحداث والفاعل التاريخي وعدم كشف الأسرار؛ أي مصدر جديد يضيف التدقيق في معاملة العملية، لا يكتب فوق أحداث سابقة. قراءة التدقيق وصلاحياته مستقلة.
- BR02/18 لجميع SYS وBR09 للجميع عدا SYS14. [قواعد العمل](../../muhaseb-erp-analysis/docs/02-accounting-and-business-rules.md).
- [القبول الأصلي](../../muhaseb-erp-analysis/docs/07-workflows-and-acceptance.md): AT02 منع التاريخ في فترة مقفلة؛ AT09 فرق صرف 2000؛ AT14 استيراد افتتاحي بلا ازدواج ومطابقة الرقابة؛ AT19 منع كشف التكلفة في كل المخرجات؛ AT25 منع مرجع من شركة أخرى؛ AT29 مطابقة الاستعادة والمرفقات. هذه معايير المصدر وليست جميعها نتائج تنفيذ لهذه الدفعة.

## نتيجة التدقيق

مطابقة 250 حقلًا و17 شاشة و22 عقدة و21 حافة، وحارس التنقل والتتبع ناجحان. لا تعديل للمصدر أو API أو SQL أو حالة الحقول. إكمال الخريطة لا يعني إكمال SYS. الشروط المستقبلية يجب إثباتها باختبارات المجال وSQL وHTTPS/JWT مع تنفيذ المستهلكين.
